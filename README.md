# 모험-스네이크 Privacy Policy

GitHub Pages로 `모험-스네이크` 앱의 개인정보처리방침을 배포하기 위한 파일입니다.

## 파일 구성

- `index.html`: GitHub Pages에서 바로 노출되는 개인정보처리방침 페이지
- `privacy-policy-ko.md`: 한국어 개인정보처리방침 원문

## GitHub Pages 배포 방법

이 저장소는 `main` 브랜치 루트의 `index.html`을 GitHub Pages로 배포합니다.

1. GitHub 저장소에서 `Settings` > `Pages`로 이동합니다.
2. `Build and deployment`에서 다음처럼 설정합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
3. 저장 후 배포 URL을 Google Play Console의 개인정보처리방침 URL에 입력합니다.
   - 예상 URL: `https://smboy86.github.io/privacy-policy-game-snake/`

## 수정 전 체크

`index.html`과 `privacy-policy-ko.md` 안의 아래 항목은 실제 앱 기준으로 꼭 확인하세요.

- 앱 이름
- 문의 이메일
- 수집하는 개인정보 항목
- 외부 SDK 사용 여부
- 계정 삭제 방식
- 보관 기간
